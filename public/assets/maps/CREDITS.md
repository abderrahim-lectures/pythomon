# Map credits

`bills-house.png` is a crop of "Bill's House" from Pokémon FireRed and
LeafGreen. Sam Webster ripped the map and posted it on The Spriters Resource.
The source page says "No credit needed". We credit him anyway.

Source: https://www.spriters-resource.com/game_boy_advance/pokemonfireredleafgreen/asset/3729/

The source image is 250 by 200 pixels. This copy removes the black border and
the caption strip, which leaves 240 by 160 pixels. The game uses its own
collision grid over the image.
