# Syllabus

The game teaches Python in one order. The topic order is numbers, decisions, text, lists, dicts, classes. It is fixed in js/challenges.js.
Every reading below comes from a cited source. The sources were opened and checked this round.

## Sources

Python Software Foundation, The Python Tutorial, section 3.1.1, Numbers, section 3.1.2, Text, section 3.1.3, Lists, section 3.2, First Steps Towards Programming, chapter 4, section 5.5, Dictionaries, and chapter 9, Classes. Site: docs.python.org.

Allen Downey, Think Python, 3rd edition, chapters 1, 2, 5, 8, 9, 10 and 14 to 17. Site: allendowney.github.io/ThinkPython.

Charles R. Severance, Python for Everybody, chapters 1, 2, 3, 6, 8, 9 and 14. Site: py4e.com.

Note. The Python Tutorial serves people who already program in some language. The game uses only small parts of it, and the game text teaches each idea first.

## Stages

Stage 0, before the first gym. The intro scene shows values on screen. Sources: The Python Tutorial, section 3.2. Think Python, chapter 1, Programming as a Way of Thinking.

Stage 1, Bitford gym, topic int. Numbers, operators and variables. Sources: The Python Tutorial, section 3.1.1. Think Python, chapter 2, Variables and Statements. Python for Everybody, chapter 2, Variables.

Stage 2, the trainer between gyms, topic bool. Decisions and comparisons. Sources: The Python Tutorial, section 4.1 and section 5.7, More on Conditions. Think Python, chapter 5, Conditionals and Recursion. Python for Everybody, chapter 3, Conditionals.

Stage 3, Quotia gym, topic str. Strings and parts of strings. Sources: The Python Tutorial, section 3.1.2. Think Python, chapter 8, Strings and Regular Expressions. Python for Everybody, chapter 6, Strings.

Stage 4, Brackett gym, topic list. Lists and their methods. Sources: The Python Tutorial, section 3.1.3 and section 5.1, More on Lists. Think Python, chapter 9, Lists. Python for Everybody, chapter 8, Lists.

Stage 5, the trainer after Brackett, topic dict. Keys and values. Sources: The Python Tutorial, section 5.5. Think Python, chapter 10, Dictionaries. Python for Everybody, chapter 9, Dictionaries.

Stage 6, the class battles, topic class. Classes, methods and objects. Sources: The Python Tutorial, chapter 9. Think Python, chapters 14 to 17, on classes and inheritance. Python for Everybody, chapter 14, Python Objects.

## Question design

The pools mix three question kinds: mc, fill and code. The game shows code first, asks for a prediction, then shows the answer. This follows PRIMM: Sentance, Waite and Kallia, Computer Science Education, volume 29, issues 2 and 3, pages 136 to 176, 2019, DOI 10.1080/08993408.2019.1608781.

The stage order also follows the view that novices build a mental model of the machine step by step: Robins, Rountree and Rountree, Learning and Teaching Programming: A Review and Discussion, Computer Science Education, volume 13, issue 2, pages 137 to 172, 2003, DOI 10.1076/csed.13.2.137.14200.

Both records were checked in Crossref (api.crossref.org). No other source is cited here.
